# structural-memory-field

This repository contains a research prototype exploring **field-based memory**,
where persistence, forgetting, and behavioral differentiation emerge from
**structural scars** rather than learned parameters or symbolic representations.

The system is not based on neural networks, transformers, or test-time heuristics,
but on local wave dynamics, erosion, and topological residue in a continuous field.

## Usage

Run `void_resonance_v2.py` directly to execute the simulation and internal verification tests.
The file is self-contained and intended for experimental inspection rather than production use.
